# Claude Code Project Instructions

This project uses the `BUILD_FROM_ZERO.md` development lifecycle.

Before any substantive task:

1.  Read `AGENTS.md`.
2.  Read `BUILD_FROM_ZERO.md`.
3.  Read `PROJECT_STATE.md`.
4.  Identify the current phase and re-read that phase in
    `BUILD_FROM_ZERO.md`.
5.  Follow the operating rules in `AGENTS.md`.

Do not rely on prior-session memory of these files.

Before declaring a task or phase complete, re-read the applicable
requirements and exit criteria, verify the work, and update
`PROJECT_STATE.md`.

`AGENTS.md` contains the shared agent rules for this repository and
should be treated as authoritative unless a higher-priority instruction
explicitly overrides it.

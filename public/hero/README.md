# EasyMail Hero Asset Pack

Drop the `hero/` folder into your project's `public/` directory, e.g. `public/hero/`.

Included:
- `hero-reference.png` — the visual target screenshot
- `gmail.svg`
- `outlook.svg`
- `yahoo-mail.svg`
- `mail.svg`
- `slack.svg`
- `google-drive.svg`
- `google-calendar.svg`
- `easymail-mail.svg`
- `category/needs-reply.svg`
- `category/needs-action.svg`
- `category/matters.svg`
- `category/can-wait.svg`

Notes:
- Brand marks are simplified vector recreations intended for hero/mockup implementation.
- Gmail and Outlook should be the primary visible providers for EasyMail. Keep Yahoo/Slack/Drive/Calendar decorative unless those integrations are actually supported.
